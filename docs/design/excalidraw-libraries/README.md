# Excalidraw libraries — bộ component để vẽ kiến trúc cho xịn

5 bộ đã tải sẵn (chọn từ kho chính chủ libraries.excalidraw.com).

| File | Item | Dùng để |
|---|---|---|
| `it-logos.excalidrawlib` | 31 | logo công nghệ (DB, cloud, ngôn ngữ, tool) — nhiều nhất |
| `dev_ops.excalidrawlib` | 29 | DevOps/infra: docker, k8s, CI/CD, registry |
| `system-design.excalidrawlib` | 24 | khối system-design: load balancer, queue, cache, DB, service |
| `awesome-icons.excalidrawlib` | 24 | icon tổng hợp đẹp, đa dụng |
| `network-topology-icons.excalidrawlib` | 10 | **bảo mật/mạng**: firewall, server, router, VPN, client (hợp pentest) |

## Cách import vào Excalidraw
1. Mở app Excalidraw (PWA).
2. Cách nhanh: **kéo–thả** file `.excalidrawlib` vào canvas → nó vào panel Library.
3. Hoặc: mở panel **Library** (icon quyển sách, góc phải) → **Load** → chọn file.
4. Import xong, các component nằm trong panel Library — kéo ra canvas mà xài.

> Bộ `network-topology-icons` đã được dùng cho canvas `pentest-architecture.excalidraw`
> (icon Server = target, Client = INPUT, Firewall = PROOF-GATE).
